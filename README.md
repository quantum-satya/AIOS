# AIOS — AI Engineering Operating System

AIOS is a documentation-first framework for building and operating
AI-assisted software engineering systems.

Its purpose is to provide reusable governance, standards, workflows,
tools, and knowledge that can be applied across multiple software
projects.

## Status

AIOS is currently under initial development.

## Scope

AIOS provides:

- Engineering governance
- AI role definitions
- Documentation standards
- Engineering workflows
- Reusable templates
- AI Engineering Platform (AIEP) guidance
- Engineering knowledge and playbooks

## Philosophy

> AI proposes. Humans decide. Engineering standards govern.

## Structure

- `docs/` — AIOS documentation
- `prompts/` — reusable AI prompts
- `scripts/` — engineering automation
- `examples/` — reference implementations
- `.github/` — GitHub configuration

## Related Projects

AIOS is designed to provide the engineering foundation for independent
projects such as STDP, SDLOS, GCT Europe, Quantum initiatives, and
future ventures.
