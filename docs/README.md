# AIOS Documentation

This directory contains the documentation that defines the AIOS
engineering framework.

Documentation is organized by domain:

- `vision/` — purpose, mission, and long-term direction
- `governance/` — rules, responsibilities, and decision-making
- `standards/` — engineering and documentation standards
- `architecture/` — AIOS architecture and design
- `roadmap/` — implementation roadmap
- `workflows/` — repeatable engineering workflows
- `templates/` — reusable documentation templates
- `playbooks/` — practical engineering procedures
- `aiep/` — AI Engineering Platform
- `knowledge/` — reusable engineering knowledge
